# The Last Signal

A psychological horror investigation, played by ear. Built to be fully playable with a screen reader. Twelve chapters in two parts, ten endings.

- `web/` – the web version (the one on Netlify). Plain HTML, CSS and JavaScript modules, no build step.
  - `web/js/content/` – the story: rooms, objects, dialogues, documents, endings.
  - `web/js/core`, `web/js/systems` – the game engine.
  - `web/audio/` – music, ambience and sound effects.
